vfr_switch (folder root):
- congestion_mgnt:
  - cgst_cllm.c / .h   <- Pengodean frame pesan CLLM (X.36 Annex C)
  - cgst_mgnt.c / .h   <- Deteksi dan pengendalian kemacetan, serta _traffic policing and shaping_
- fr_switching:
  - fr_frame.c / .h             <- Pengodean frame dan alamat Q.922, HDLC, CRC-16
  - fr_switch.c / .h            <- Inti mesin switching frame (DLCI)
  - svc_routing_common.c / .h   <- Kode bersama dan pengendali utama proses switching untuk SVC
  - svc_routing_nni.c / .h      <- Pengendali proses switching SVC untuk antarmuka NNI
  - svc_routing_uni.c / .h      <- Pengendali proses switching SVC untuk antarmuka UNI
- ports/:
  - lapf/port_lapf.c / .h                <- Tumpukan protokol LAPF (Q.922) untuk SVC dan penyaringan protokol LMI
  - pcap/port_pcap.c / .h                <- Pembuat dan penulis tangkapan paket PCAP
  - port_common.c / .h                   <- Komponen bersama untuk antarmuka-antarmuka
  - port_pipe.c / .h                     <- Kode untuk antarmuka "pipa bernama"
  - port_serial.c / .h                   <- Kode untuk antarmuka port serial
  - port_tcp.c / .h                      <- Kode untuk antarmuka soket TCP
  - port_udp.c / .h                      <- Kode untuk antarmuka soket UDP
  - svc_numbering/svc_numbering.c / .h   <- Kode untuk register penomoran untuk SVC dan untuk pengelolaan sistem penomoran X.121
- pvc/:
  - pvc_lmi_ansi.c / .h    <- Tumpukan protokol LMI tipe ANSI T1.617/T1.618 (UNI)
  - pvc_lmi_gof.c / .h     <- Tumpukan protokol LMI tipe Gang of Four (Cisco/DEC/Nortel/StrataCom) (UNI)
  - pvc_lmi_q933a.c / .h   <- Tumpukan protokol LMI tipe Q.933 Annex A/Klausa 11 X.36 (UNI) dan Klausa 11 X.76 (NNI)
  - pvc_mcast_nni.c / .h   <- Pengendali proses Frame Relay PVC Multicasting (1-way/2-way/n-way) untuk NNI
  - pvc_mcast_uni.c / .h   <- Pengendali proses Frame Relay PVC Multicasting (1-way/2-way/n-way) untuk UNI
- svc_signalling/:
  - svc_sig_common.c / .h   <- Kode bersama dan pengendali utama proses persinyalan dan routing SVC
  - svc_sig_iel.c / .h      <- Kode yang berisi tabel dan format Information Elements untuk persinyalan SVC X.36 dan X.76
  - svc_sig_iep.c / .h      <- Kode untuk memproses Information Elements untuk persinyalan SVC X.36 dan X.76
  - svc_sig_nni.c / .h      <- Pengendali proses persinyalan dan routing SVC untuk NNI (Klausa 10 X.76)
  - svc_sig_uni.c / .h      <- Pengendali proses persinyalan dan routing SVC untuk UNI (Klausa 10 X.36)
- vfr.h         <- Platform foundation (stdlib, mutex, threading, logging)
- vfrs_main.c   <- Entry point (renamed from vfr_main.c)
- Makefile
